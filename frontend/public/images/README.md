# UoS Logo

Place the University of Suffolk logo here.

## Files needed:
- `uos-logo.png` - Main logo (recommended size: 200x200px)

## How to get the logo:
1. Visit the University of Suffolk brand guidelines
2. Download the official logo
3. Save as `uos-logo.png` in this folder

## Note:
If no logo is provided, the app will display without the logo.
